# Particle Coherency Power Systems Lab V1

The IEEE 9-bus topology follows Fig. 7 of Chamorro et al., Power Systems Coherency Representation and Identification as Particles (2022). The 10-machine network is illustrative. The model solves incremental linearized swing equations with algebraic passive buses and midpoint integration, 10 ms samples, 12 s duration. Fault proxy reduces coupling and applies imbalance from 10 to 50 ms. No original machine parameters or recorded traces are available. Snapshot buttons correspond to paper times, not reproduced numerical results. Direct speed mapping follows figures; angle mapping integrates speed deviation with base angular frequency. Direction mismatch uses a normalized indicator rather than literal signed Eq. 6. Optional strict proximity over the trailing window implements the concordance concept. FoF connected components may contain pairs without direct links. Accumulated motion is not an inertia estimate. Group colors use component representatives and are not persistent IDs.
